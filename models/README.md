# Веса Attention518

Веса не входят в облегчённую GitHub-версию. Получите `model_complete_primary.zip` у команды.
Датасеты train/validation/test также не включены.

```powershell
python scripts/install_attention518.py "C:/path/to/model_complete_primary.zip"
```

Размер архива: 659303075 байт.
SHA-256: `68894a977620a3c5b0ac07f0677e79ebcc3f9941d3b517d7c31f49c88071f43a`.
Установщик проверяет SHA-256 и распаковывает архив в `runtime/attention518`.
Без отдельно полученных весов инференс недоступен.
